# Tetrix
Tetris-like game on SDL2. License GPL v3.


## Dependencies
- [SDL >= 2.26.4](https://github.com/libsdl-org/SDL)
- [SDL_ttf >= 2.20.2](https://github.com/libsdl-org/SDL_ttf)
- [SDL_image >= 2.6.3](https://github.com/libsdl-org/SDL_image)
- [Check >= 0.15.2](https://github.com/libcheck/check)
